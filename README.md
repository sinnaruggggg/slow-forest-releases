# 느린 숲 · Slow Forest

Android 가로 전용 미니어처 꽃농장 힐링 게임입니다.

[최신 APK 다운로드](https://github.com/sinnaruggggg/slow-forest-releases/releases/latest/download/slow-forest.apk) · [버전별 릴리즈](https://github.com/sinnaruggggg/slow-forest-releases/releases) · [최신 버전 정보](latest.json)

Android 8.0 이상에서 사용할 수 있습니다. 현재 배포 파일은 개발용 서명 APK입니다.

작은 집과 두 화단에서 시작해 꽃을 재배하고 화원을 확장합니다. 두 정원지기 중 하나를 고르고 기초 안내를 따라 시작할 수 있습니다.

이 저장소는 검수한 APK, 버전 정보와 변경 사항을 배포합니다. 앱 소스와 사용자 저장 데이터는 포함하지 않습니다. 새 검수 APK를 올리면 Release 워크플로가 latest.json을 자동 갱신하며 최신 APK 다운로드 주소는 그대로 유지됩니다.
